# portal-request-view – public pages for Portal Request View Plus

GitHub Pages project site for the Portal Request View Plus Forge app. Because the account's
user site (`rishabhchulet.github.io`) has the custom domain `creet.in`, GitHub serves this
repository at `https://creet.in/portal-request-view/`.

| File | What it is |
|---|---|
| `index.html` | Overview: what customers see, setup, data handling |
| `privacy.html` | Privacy policy, linked from the app's Forge distribution settings |
| `terms.html` | Terms of service, linked from the app's Forge distribution settings |
| `prv.css`, `icon.svg` | This product's colour, panel mock-up styles and icon |

The pages reuse the shared `styles.css`, `theme.js` and `icon.svg` of the user site through
`../` links, so they look like the rest of creet.in. Publish: push to `main` (Pages source:
`main`, root). Support contact: support@creet.in.
